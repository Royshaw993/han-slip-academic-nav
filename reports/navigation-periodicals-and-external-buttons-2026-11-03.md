## 3种刊物的入口

原先需要进入“全部学术资源”，再选“📚 学术期刊”；该筛选还混入知网、中国社会科学网、JSTOR等平台，且没有集中展示本站关联论文。

现在总览新增 **“学术期刊与集刊 · 3种”** 直达入口。它仍调用原 `resources` 模块并选中原分类值 `📚 学术期刊`；不建立新路由、刊物副本或论文副本。分类按钮显示“学术期刊与集刊”，仅筛选已有 `displayCategory` 为学术期刊／学术集刊的3条记录。知网等平台继续留在网站目录，卡片标为“学术检索与资讯”。

| 既有刊物ID | 刊物 | 本站关联论文数 |
| --- | --- | --- |
| `chutu-wenxian-journal` | 《出土文献》 | 3 |
| `chutu-wenxian-yanjiu` | 《出土文献研究》 | 6 |
| `chutu-wenxian-falvshi` | 《出土文献与法律史研究》 | 0 |

刊物介绍、责任机构和“查看刊物信息”入口读取原资源记录；下方原生折叠区复用论文卡片。按已核 `paper.journal` 与刊名规范化后的**完整名称**匹配，不使用标题前缀或主题词推测关系。原检索词表补入“獻→献”，使N10的“出土文獻研究”正确关联，显示原文不变；《出土文獻研究視野與方法》不会混入。《出土文献》沿用原同名辑刊／期刊整体记录，兼收其前身阶段论文。法律史集刊如实显示“本站暂未收录该刊论文”。

直达时暂时解除目录方向标签限制，确保3刊可见；返回后恢复原目录筛选、滚动位置和新入口焦点。搜索往返保留刊物折叠区状态。

## 外链按钮

`.visit-button`、`.update-link`、`.classic-paper-link` 共用一组公共CSS：暖米色背景、暗红文字、浅棕1px边框、统一内边距与44px最小点击高度。移除各模块黑色实心样式；保留浅暖色hover、3px键盘焦点以及disabled样式。论文操作区换行时保留纵向间距。

| 用途 | 文案处理 |
| --- | --- |
| 已核全文、PDF、节选 | 保留“阅读原文”、PDF格式标识、“阅读节选”；全文访问类型不变。 |
| 论文信息页 | 保留“查看论文信息”。新论文动态使用同类信息文案，避免将信息页称为全文。 |
| 既有CiNii书目入口 | “查看书目记录”改为“查看馆藏信息”。 |
| 论文附带出版目录／书目、书讯动态 | 使用“查看出版信息”，保留原有“2019年文集重收”“作者书目”等上下文。 |
| 刊物信息页 | 保留“查看刊物信息”。 |
| 其他动态来源正文 | “查看原文”改为“阅读原文”；资源平台保留其实际访问用途文案。 |
| 无URL / TODO | 不生成空链接、占位按钮或伪阅读入口；历史补录、示例等内容标签保持。 |

所有既有URL、`target="_blank"` 和 `rel="noopener noreferrer"` 保持；本轮未新增外部链接，也未重新抓取远端页面。测试验证站内生成的目标与打开属性，不把这些检查当作远端可达性复核。
