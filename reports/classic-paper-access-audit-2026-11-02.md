## 方法、证据边界与纠正

1. 优先尝试 Chrome 浏览器连接，工具返回 `The browser access host is unavailable`。随后按电脑操作技能尝试 Windows 桌面通道，重试及重新初始化后仍报 `Computer Use native pipe is unavailable`。因此没有实际点击浏览器按钮，也没有使用用户登录态；不能把下列结果描述成“9篇均经过浏览器点击验证”。
2. 通过本机未登录的公开网络 GET 取得当前URL和候选替代来源，保存页面正文、最终URL和文件；同时用网页检索工具交叉核对题录、摘要及链接。最初沙箱的 EACCES 是工具网络权限问题，已通过只读网络访问复查，不计为网站故障。
3. 真正取得的PDF用本机PDF引擎打开、渲染并目视检查首部、正文抽样及末部。文件头、页数和页内题名共同核对，不以HTTP 200或文件名代替正文检查。
4. 检索工具会读取历史索引。O3的根目录PDF能从检索工具读到40页旧内容，但本机当前 GET 返回404；本报告以当前直连结果判定该下载入口不可用。工作中的初步判断已据此修正。
5. 本轮未登录、未支付、未绕过验证码、证书或访问限制。登录后的下载、订阅权限、浏览器弹窗和移动端外站体验凡未实测者均保留“未确认”。
6. 前轮代码回归只证明本站渲染、搜索和状态恢复，没有证明外部论文可读；前轮“验收通过”不能继续作为外链可用性的依据。

“本机成功”只表示本次网络条件下成功，不承诺所有地区持续可用；“连接失败”也不等同于文献不存在或永久失效。
