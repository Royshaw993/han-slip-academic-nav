# V1.3 学科页面统一实施报告

日期：2026-11-04。本轮在已有未提交修改上继续实施，保留原有工作；未 commit、push 或部署。

## 页面结构

- 甲骨文、金文、石刻、汉简共用顺序：最新学术动态 → 研究专题 → 学术网站与数据库 → 研究文献 → 学术导航总览。
- 复用原甲骨文页的紧凑资源卡片、暖米色与暗红色样式，以及既有分页、文献卡片和导航组件。浏览器比对确认甲骨文资源网格列宽、间距、内边距、边框及背景保持一致。
- 汉简不再单列著作、论文、整理本等大区块，统一放入“研究文献”，直接引用正式书目和论文对象，以已有类型标签区分。综合预览兼顾论文与书目，每项只出现一次。
- 资源和文献默认显示4项，每次增加至多4项，支持收起。研究专题继续使用既有简洁入口；现有单个学科最多4个，无需新增展开控件。
- 石刻尚无可靠关联的研究专题和正式文献，隐藏这两个空区块；已有资源和动态正常展示，不补造内容。
- 保留动态类型和研究对象筛选；修正 CSS 对 hidden 属性的覆盖，非简牍页面不再留下空的研究对象标签行。
- 新文献区加入统一搜索的浏览快照。搜索、专题和完整目录返回均保留展开状态、滚动位置与键盘焦点；无 URL 的文献保留题录，不生成空链接。

## 动态归属

旧门类筛选使用标签子串匹配，且“拓片”被视为石刻归属条件，存在将通用关键词或跨材料影像误归类的风险。本轮收紧为明确门类、研究对象标签的完整匹配，并复用专题已有的对象关联；不根据来源网站、资源链接或“古文字”“出土文献”等宽泛标签推断学科。不能确认的动态继续保留在全站。

当前金文页的4条正式动态逐条检查后均有明确金文关联：《出土文献》2026年第3期、古文字研究会第二十六届年会、《汉字汉语研究》2026年第4期及《簡帛》第三十二辑。《簡帛》书讯现有摘要和标签明确涉及金文，因此保留这一跨学科条目；不能仅凭刊名或简帛网来源判定无关。悬泉缀合、肩水金关释文、张家山校读等无关动态未进入金文页。

未修改任何正式动态的事实、日期、来源或原始标签，也未删除正式动态。
